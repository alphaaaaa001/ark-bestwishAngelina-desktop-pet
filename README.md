# 🐾 安洁莉娜 桌面宠物

> **基于 Electron + webm 的安洁莉娜透明桌面宠物：9 种动作、滚轮缩放、拖动走路、随机互动，无需 GPU。** webm素材来自《明日方舟PRTS》，仅供学习交流。
>
> Arknights Angelina desktop pet built with Electron + webm: 9 animations, wheel zoom, drag-to-walk, random interactions. No GPU required. Assets from Arknights, for learning only.

她会待在你屏幕角落，等你戳她、拖她、让她陪你摸鱼。

> 不需要 GPU / WebGL——普通核显笔记本也能跑。

## ✨ 功能

| 操作 | 效果 |
|---|---|
| **点击** | 随机互动：撒娇 / 小招 / 技能，弹台词气泡 |
| **按住拖动** | 她走路的姿势移动；松手记住位置，下次启动还在这（重力模式下松手会自由落体） |
| **鼠标滚轮** | 放大 / 缩小她（最小 30% ~ 最大 200%），窗口跟随收放，重启后记住大小 |
| **右键** | 菜单：撒娇 / 坐下 / 睡觉 / 醒来 / 放大招 / 重力开关 / 背面视角 / 播放曲子 / 退出 |
| **平时** | 待机 + 每 9~21 秒随机做一个动作、说句话 |

9 个动作：待机 / 走路 / 坐下 / 撒娇 / 放松 / 睡觉 / 小招 / 大招 / 攻击，全部来自官方 webm 素材，黑底会被 Electron 透明窗口自动吃掉，只留下她。

## 🚀 快速开始

**方法一（最简单）**：双击 `start.bat`。依赖齐全时秒开；缺依赖会自动走国内镜像补装。

**方法二（命令行）**：

```bash
npm start
```

> 若无法运行：先看下方「常见问题」，本机实测过的坑都写在那。

## 📁 文件结构

```
cc-desktop-pet/
├─ main.js          # 主进程：透明置顶窗口、拖动手势、右键菜单、位置记忆
├─ preload.js       # 安全 IPC 桥
├─ index.html       # 页面：容器 + 视频 + 气泡

└─ assets/          # 9 个动作的 webm 素材
```

## ⚙️ 技术说明（写给想折腾的人）

- **黑底透明原理**：素材是 RGB(1,1,1) 的伪黑幕，Chromium 在合成时会剔除接近纯黑的像素，透明窗口因此只露出人物，无需抠图。
- **人物裁剪定位**：素材画布统一 1000×1000，人物只在其中一块区域。每个动作记录 bbox，用「绝对定位 + object-fit:fill + overflow:hidden 容器」把 bbox 区域对齐到窗口——不要用 transform + object-fit:none，在 DPI 缩放下会错位（实测的坑）。窗口本身也按 bbox 实时变形：站姿窄高、睡姿扁宽，身体像素密度恒定，她不会随动作忽大忽小。
- **拖动手势**：由主进程轮询 `screen.getCursorScreenPoint()` + `setBounds` 移动窗口——DPI 缩放下渲染进程的 `PointerEvent.screenX` 与主进程坐标单位不一致，会让窗口跑偏/加速（实测的坑）。
- **位置记忆**：存在 `%APPDATA%\ark-anglina-desktop-pet\pet-state.json`（以 package.json 的 name 命名，不是文件夹名），删掉即重置位置和缩放。
- **动画切换**：所有视频预加载但**错峰**（无 GPU 机器上 9 个 webm 同时解码会卡）。
- **缩放记忆**：滚轮调好的大小防抖后存进 `pet-state.json`（和位置记忆同一份），重启自动恢复。
- **重力模式**（点按开关，不持久化）：右键菜单或 `curl /action -d '{"action":"gravity"}'` 切换。开启后拖动松手，她会按**钱学森弹道**飞回来：下降动画与拖动同款（正面走路 / 背面起飞），伪随机横向机动（比例导引朝随机目标点）+ 三成概率进入滑翔段上飘，飞行约 5 秒后轻点一下地收稳，地面 = 工作区底边（站在任务栏顶上）；贴地锁保证动作变形时脚底不飘。物理只在主进程跑，拖动一开始就掐断重力循环。（安洁莉娜本来就操纵重力，怎么会让自己摔呢）
- **情境感知**（2026-08-29）：夜里 22 点后随机动作换夜猫子行为池+台词（「你还不睡吗？」）；作息系统——工作日 0~8 点 / 周末 0~9 点自己睡觉、到点伸懒腰自然醒（周末赖床到 9 点），被强行叫醒给 10 分钟面子后继续睡；冷落感知——30 分钟没人理坐下等你、60 分钟等到睡着，戳醒有起床气（attack+专属台词）；8 秒内连戳 5 次以上，一半概率她要打你。
- **调试抓帧**：`CC_PET_DEBUG=1 npm start` 才会在启动 5 秒后写 `capture.png`（平时不覆盖）。

## 🐛 常见问题

- **窗口拖动时变大/跑偏** → 已修复（主进程 setBounds 轮询）。若还异常，检查系统 DPI 缩放比例。
- **动画播完变透明** → 已修复（同源续播 + 预加载）。若切换动作有加载空窗，说明机器解码慢，可减少预加载数量。
- **黑底没被吃、人物带黑框** → Electron 版本过旧，或窗口没设 `transparent: true`。
- **npm 装 Electron 卡死** → 用上面的 `ELECTRON_MIRROR` 国内镜像。
